# 要求记录(Requirement Record)

> 本文件记录用户提出的全部原始要求与历次澄清,按时间序。方案据此演进,冲突时以最新澄清为准。

## 已确认要求

1. **统一调度多 agent**:软件可关联电脑上已安装的多个 agent 客户端(初始提及 ZCode、WorkBuddy、TRAE SOLO CN、Qoder、商汤小浣熊)。
2. **核心目的 = 套餐池化**:把各 agent 客户端的付费套餐结合一起用(统一入口派发任务、消耗各客户端套餐额度),**不是**让各软件之间跨来跨去(agent 互跳委派降级为可选)。
3. **执行方式**:通过电脑上已安装的客户端软件本身操作,不使用 API、不做反代路由,以免被官方风控。
4. **独立项目**:不与已有项目 AgentHub 结合,单独立项。
5. **控制粒度**:可以控制各个 agent;可以选中各个 agent 所能使用的模型。
6. **唤起能力**:增加唤起(已安装的)软件的功能;增加一键唤起。
7. **logo 标识**:各软件的任务展示各自不同的 logo。
8. **整合交互**:展示形式、任务派发形式、界面样式、操作逻辑等都整合优化进方案。
9. **方案审核**:要求检查方案存在的问题与逻辑遗漏,输出一套完整、可实行的方案。
10. **本轮定位**:先进行测试验证并输出可执行方案,**不是直接出产品**。
11. **最终版要求**:多轮评估、每轮优化;完善设计与落地每一步、使用者操作;补齐各种存储性质与实际控制性质;输出最终方案版,使 AI 可据此直接生成完美落地的项目,不遗漏细节与操作逻辑。
12. **多轮复审**:再次审核方案漏洞并补全(第四轮评估,产出 v4 定稿)。
13. **仓库与发版定版**(2026-10-01):git 远程迁移 **GitHub(https://github.com/HUIdada1/AgentDrove.git)**,原 Codeup 仓库降为备用 remote;**exe 发版同样走 GitHub Releases**;软件署名作者**沐辉**;**仅提供安装版(NSIS),无需便携版**;GitHub 访问先走本机代理(实测 `git ls-remote` 连通)。
